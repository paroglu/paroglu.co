PAROĞLU MEDIA — V9 / PAROĞLU MODE

Bu sürüm mevcut premium siteyi OFF durumunda aynen korur.
PAROĞLU MODE ON olduğunda lazy-load edilen, tam ekran pixel portfolio katmanı açılır.

Öne çıkanlar:
- Demo referansına yakın mor pixel dağ/orman dünyası
- IAM PAROĞLU hero, pixel tipografi, soru kutuları
- Özgün fotoğrafçı avatarı (gözlük + kamera)
- 7 dünya: Konser, Spor, Reels, Fotoğraf, Drone, Tasarım, Prodüksiyon
- Klavye (A/D, oklar, Space/Enter/Esc), mouse ve swipe kontrolleri
- Zıpla + soru kutusuyla proje açma
- Konser ve ACK Bıçak gerçek video preview'ları
- Instagram Reels paneli: otomatik başlatma denemesi, 10 sn'de bir değişim, kapanınca iframe/ses kesme
- OFF ile aynı scroll noktasında normal siteye dönüş
- Mode assetleri kullanıcı ON'a basana kadar yüklenmez
- Masaüstü / iPad / mobil responsive kurallar
